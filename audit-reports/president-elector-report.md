## Finding 1: EIP-712 TYPEHASH Type Mismatch — Signature Verification Bypass

**Severity**: 🟠 HIGH | **Pattern**: EIP-712 Compatibility

#### Description
The `TYPEHASH` constant declares `uint256[]` but the actual function parameter is `address[]`. Any EIP-712 compliant signing tool (Metamask, ethers.js) will generate incompatible signatures, forcing users to use non-standard tooling or blocking them entirely.

#### Vulnerable Code
```solidity
// RankedChoice.sol:23
bytes32 public constant TYPEHASH = keccak256(
    "rankCandidates(uint256[])"  // ⚠️ uint256[] — should be address[]
);

// Used in:
function rankCandidatesBySig(
    address[] memory orderedCandidates,  // This is address[], not uint256[]
    bytes memory signature
) external {
    bytes32 structHash = keccak256(abi.encode(TYPEHASH, orderedCandidates));
    // ⚠️ abi.encode(TYPEHASH, address[]) ≠ expected TYPEHASH(uint256[])
    address signer = hash.recover(signature); // Signature verification inconsistent
}
```

#### Impact
1. User signs `rankCandidates(address[])` via ethers.js — computed TYPEHASH = `keccak256("rankCandidates(address[])")`
2. Contract uses TYPEHASH = `keccak256("rankCandidates(uint256[])")` — different value
3. Signatures NEVER match → **all meta-transactions permanently broken**
4. Self-consistent IF both signer and contract use same wrong TYPEHASH — but standard tools won't

**Severity Justification**: Breaks EIP-712 compatibility; renders gasless voting unusable with standard wallet providers.

#### PoC
```solidity
function testTypeMismatch() public {
    // Standard EIP-712 signing (ethers.js `_signTypedData`)
    // signs "rankCandidates(address[])" → TYPEHASH_A
    
    // Contract expects "rankCandidates(uint256[])" → TYPEHASH_B
    
    // TYPEHASH_A ≠ TYPEHASH_B → signature mismatch
    bytes32 structHashContract = keccak256(abi.encode(
        keccak256("rankCandidates(uint256[])"), // ← contract uses uint256[]
        orderedCandidates
    ));
    
    bytes32 structHashStandard = keccak256(abi.encode(
        keccak256("rankCandidates(address[])"), // ← standard tools use address[]
        orderedCandidates
    ));
    
    assertNotEq(structHashContract, structHashStandard);
}
```

#### Recommended Mitigation
```solidity
// CORRECT: match parameter types exactly
bytes32 public constant TYPEHASH = keccak256(
    "rankCandidates(address[])"  // ← address[], not uint256[]
);
```
