# 安全分析: xiaolai/ai-cli-kickstarter

## 项目概况

- **作者**: 李笑来 (xiaolai)
- **目标**: 完全不懂计算机的人安装第一个 AI CLI
- **状态机**: LANGUAGE→PROBE→SELECT→PRECHECK→CONFIRM→INSTALL→VERIFY→HANDOFF
- **支持**: Qwen Code / Kimi Code / CodeBuddy CLI / macOS/Linux/Windows

## 安全分析

### ✅ 做得好的地方

| 方面 | 细节 |
|------|------|
| URL 硬编码 | 三个官方URL写死，无用户输入拼接 |
| 状态机严格 | 每步必须用户确认才能继续 |
| 显示来源 | 执行前显示完整下载URL |
| 幂等重试 | 失败可重试/换工具/退出 |
| 信任声明 | README明确写着"运行即表示信任这些来源" |

### ⚠️ 值得注意

| 问题 | 影响 |
|------|------|
| 无完整性校验 | 不验证下载脚本的hash/签名 |
| curl 管道执行 | `curl ... \| bash` 模式 |
| Google 检测 | 仅测连接性，不推断位置 |

### 风险评估

**低风险** — 代码简洁(200行)、URL硬编码、无外部输入注入点。唯一风险点是管道执行模式(`curl | bash`)，但这是所有在线安装器的通病。

## 技术亮点

- **双语状态机**: 中英文切换通过函数映射实现，不重复逻辑
- **bash/ps1镜像**: 两个脚本同步维护，功能一致
- **幂等设计**: 重试、换工具、退出三选一
- **新手友好**: SmartScreen提示都考虑了

## 对你有什么用

这本质是一个"**给AI装AI**"的工具——装一个CLI AI，然后让AI接管后续所有操作。Prompt库里10个任务从"初始化电脑"到"局域网审计"，每个都是完整Mission。

**启发**: 你的AI Auditor Agent可以加这种新手引导状态机——让不懂安全的人也能用你的58模式扫描器。
