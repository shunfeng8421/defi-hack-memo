# DeFi Threat Model & Attack Surface Analysis

## 1. 与传统系统的安全模型差异

```
传统 Web 安全:
  攻击者 ──→ 输入验证 ──→ SQLi / XSS / SSRF
  防御: WAF + 输入过滤 + 沙箱

DeFi 安全:
  攻击者 ──→ 经济激励 ──→ 闪贷 / 价格操纵 / 治理
  防御: 协议设计 + 预言机 + 时间锁
```

**核心差异**: DeFi 攻击者不需要"闯入"系统——他们可以直接利用**系统允许的操作组合**来获利。

## 2. 攻击者模型

| 等级 | 能力 | 典型攻击 |
|:--:|------|------|
| L1 | 普通用户 | 在公开接口调用函数 |
| L2 | 闪贷用户 | 在一个交易中借入任意金额 |
| L3 | 验证器/MEV | 排序/插入/删除交易 |
| L4 | 内部人员 | 有敏感权限的后台/密钥 |

**本文覆盖**: L1 + L2 (824 个案例中 ~85% 是 L1/L2 级攻击者)

## 3. DeFi 特有的攻击面

```
┌──────────────────────────────────────┐
│             DeFi 攻击面              │
├──────────────────────────────────────┤
│ 1. 预言机层   ← 价格输入点              │
│    • AMM 瞬时价格 (getReserves)        │
│    • Chainlink 延迟                    │
│    • 自建预言机                        │
├──────────────────────────────────────┤
│ 2. 流动性层   ← 池子状态                │
│    • AMM 单边操纵                      │
│    • 捐赠攻击 (强制转账)                │
│    • sync() 价格扭曲                   │
├──────────────────────────────────────┤
│ 3. 借贷层     ← 抵押/清算               │
│    • 清算阈值绕过                      │
│    • 健康因子操纵                      │
│    • 利息累计错误                      │
├──────────────────────────────────────┤
│ 4. 跨链层     ← 消息传递                │
│    • 验证器签名绕过                    │
│    • 重放攻击                          │
│    • 中继器作恶                        │
├──────────────────────────────────────┤
│ 5. 治理层     ← 升级/修改                │
│    • 闪贷投票                          │
│    • 时间锁绕过                        │
│    • 代理存储碰撞                      │
├──────────────────────────────────────┤
│ 6. 代币层     ← ERC 标准实现             │
│    • 转账 hook 重入 (ERC-777)          │
│    • 精度截断                          │
│    • 授权竞争 (front-run approve)      │
└──────────────────────────────────────┘
```

## 4. 防御成熟度模型

| 阶段 | 防御 | 效果 | 覆盖 |
|:--:|------|:--:|:--:|
| 0 | 无防御 | — | 2017-2019 |
| 1 | 基础检查 (非Reentrant等) | ↓ 重入 90% | 2020+ |
| 2 | 自动化扫描 (Slither) | ↓ 代码级漏洞 70% | 2021+ |
| 3 | 模糊测试 (Foundry) | ↓ 边界漏洞 60% | 2022+ |
| 4 | 形式化验证 (Certora) | ↓ 逻辑漏洞 50% | 2023+ |
| 5 | AI 辅助审计 | ↓ 业务漏洞 ?% | 2025+ |

## 5. 未来威胁 (2026-2027)

| 威胁 | 受影响的 | 攻击面 | 新特点 |
|------|------|------|------|
| AI Agent 合约 | AI×区块链协议 | 代理权限 | Agent 有自主决策能力 |
| L2 排序器攻击 | Optimism/Arb/zksync | 交易排序 | 比 MEV 更底层 |
| Intent 协议 | UniswapX/CoWSwap | solver 操纵 | 链下求解器的信任 |
| ZK 电路漏洞 | zkSync/Scroll | 证明伪造 | 非传统代码审计 |
