## 使用方法

### 1. 按年份浏览

查看 `INDEX.md` 找到感兴趣的案例, 或直接浏览 `cases/` 目录

### 2. 按攻击模式浏览

查看 `patterns/` 目录, 每个模式文件包含: 原理, 检测方法, 修复方案, 对应真实案例

### 3. 审计时对照

审计一个新合约时, 对照 `patterns/` 检查 50 个模式是否被正确实现
